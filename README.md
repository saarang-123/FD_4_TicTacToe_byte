# Tic Tac Toe Game

A responsive two-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

## Features

* Two-player gameplay
* Interactive 3×3 game board
* Win and draw detection
* Game reset functionality
* Player turn indicator
* Responsive design for desktop and mobile

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns selecting an empty cell.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Click the reset button to play again.
